# PRODUCT.md — CheckMyPaper

**Register:** product (app UI — a task tool that happens to be playful).

**What:** A mistake-diagnosis + practice PWA for JEE aspirants. Scan a mock →
talk through your mistakes → see your patterns → battle weak topics → chat with
an AI coach. Local-first, installable.

**Audience:** Indian teens, ~15–18, born late-2000s+ (Gen Z/Alpha). Phone-native,
fluent in TikTok/Duolingo/gaming UIs. Bored by clinical edtech. Motivated by
progress, streaks, rank, and "this gets me."

**Tone:** Encouraging coach, not a scolding teacher. Confident, warm, a little
playful — never babyish, never corporate. Honest ("here's your leak") + hopeful.

**Design direction:** Friendly-serious. Rounded, tactile, gamified surfaces on a
soft violet canvas; **purple = identity/brand, mint-green = the go-action**.
Depth via soft layered shadows and gentle background glow — not flat. A rounded
display face (Fredoka) for titles + a clean geometric UI face (Plus Jakarta Sans)
for everything else. Motion conveys state (tactile button press, progress,
selection), never decorative page-load choreography.

**Anti-slop guardrails:** no system-font default look, no gradient text, no glass
cards, no per-section eyebrows, no flat gray-on-lavender low-contrast text. Body
text hits ≥4.5:1. One consistent button/chip/card vocabulary across every screen.
